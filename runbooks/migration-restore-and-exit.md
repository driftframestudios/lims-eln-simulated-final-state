# Representative migration, restore, and exit rehearsal

1. Freeze a signed source snapshot and delta boundary.
2. Record source, schema, configuration, identity, and artifact manifests.
3. Transform into versioned canonical records.
4. Reconcile identity, revision, lineage, scientific semantics, audit, and bytes.
5. Exercise a changed-content collision and record accountable disposition.
6. Run delta catch-up and shadow read comparison.
7. Exercise authority transfer and timed rollback.
8. Restore into a clean environment using a second trained operator.
9. Perform independent readback and compare the signed manifest.
10. Remove ordinary vendor access and reconstruct the neutral data-exit package.

Each boundary provides a continuation path: reconciliation returns mismatches to a
bounded correction queue, rollback returns authority to the signed source boundary,
and restore variance opens an investigation with the environment preserved.
