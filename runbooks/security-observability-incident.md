# Security and observability incident exercise

1. Seed an approved synthetic cross-tenant request and protected trace value.
2. Confirm the tenant boundary returns the request to the governed transfer path.
3. Confirm the telemetry filter replaces the protected value with class and digest.
4. Interrupt the telemetry destination and retain bounded local delivery state.
5. Restore the destination and reconcile trace, metric, and alert continuity.
6. Rotate the workload credential and verify the fresh identity path.
7. Record good events, valid events, threshold, window, and observed ratio.
8. Page the secondary responder and exercise the laboratory continuity procedure.
9. Bind findings, raw-artifact digest, reviewer, disposition, and retest trigger.

Production exercises use approved probes and accountable incident ownership. This
runbook's generated result stays visibly simulated until an observed envelope passes
the comparative-evidence admission gate.
