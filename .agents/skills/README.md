# Repository-local skill catalog

These four portable contracts help a collaborator choose a bounded workflow for
the Simulated Final State repository. Begin with the repository's
[`AGENTS.md`](../../AGENTS.md) for current source, branch, evidence, and
validation guidance; use this catalog when the work needs one of the more
specific routes below.

## Choose by reader job

| Situation | Skill | Expected return |
| --- | --- | --- |
| A resumed task needs current branch, accepted release, living orientation, and comparison state reconstructed | [`repository-reentry`](repository-reentry/SKILL.md) | A compact current-truth receipt and one exact re-entry action |
| A claim could blur assumptions, executable behavior, generated artifacts, release evidence, or receiving use | [`source-authority-mapping`](source-authority-mapping/SKILL.md) | An authority map with distinct owners, projections, and promotion events |
| A sibling release changes the current constellation coordinate | [`constellation-coherence-reconciliation`](constellation-coherence-reconciliation/SKILL.md) | Reconciled current orientation records and one named receiver while signed release bytes stay stable |
| Public or cross-repository prose may rely on local shorthand | [`contextual-jargon-scan`](contextual-jargon-scan/SKILL.md) | Defined necessary terms and clearer ordinary-language routes where meaning improves |

## Standing and authority

Each skill carries `source_band: public_possible` and exact upstream lineage in
its front matter. That band records a candidate collaboration surface; current
user intent, repository evidence, and granted tool authority continue to govern
each activation. Natural use can refine local fit, and a separate public-ready
review is the promotion event for any future public projection.

The skills route work; they do not replace the owners of repository behavior.
Runnable source and tests own current behavior, the role manifest and retained
release evidence own accepted coordinates, and the Coordination Horizon and
First Receipt own the current receiver.

## Return

Return the changed source or decision surface, the smallest observation that
establishes it, the evidence ceiling, and the exact role or artifact that can
continue. When no skill adds decision value, direct reasoning remains the
smallest adequate route.
