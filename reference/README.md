# Non-runtime reference material

This directory preserves earlier exploratory implementations for historical
comparison. Files here are excluded from the installed package, the command-line
evaluation, and CI execution.

`quarantine/database/database_oracle_validator.py` documents the earlier detailed
database-contract comparison. The validator and its full oracle inputs remain
available for study.

`quarantine/control-plane/` contains the former bounded-caller, modeled receipt,
and simulated-closure implementation.

`quarantine/` contains the earlier acceptance drafts, release manifests,
first-receipt record, and Coordination Horizon. The active Machine Node points to
this location as historical material.
