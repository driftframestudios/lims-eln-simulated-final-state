# Quarantined control-plane prototypes

These modules record a prior exploration of bounded callers, modeled acceptance,
and simulated closure receipts. They are not imported by `lims_eln_sim`, packaged
as runtime code, executed in CI, or treated as evidence of an organizational
decision.

They remain solely to make the collaboration history inspectable while the active
repository stays focused on vendor behavior, data portability, configuration
references, event-envelope outcomes, and synthetic comparison results.
